## How to read this

* A **claim** is a row the pipeline resolved to a name. Unnamed rows are flagged for review, cost recall, and are never counted as false positives — scoring them as errors would reward dropping a doubtful row over surfacing it.
* Two names are the same drug when their normalised forms are equal, when one token list starts the other, or at ≥ 88/100 whole-string agreement. Every pair records which rule fired, in the JSON alongside this file.
* Medicines a transcriber marked `certain: false` are excluded from both precision and recall (4 prediction(s) landed on one here).
* Generated by `make bench` (`python -m backend.ocr.benchmark`). See `docs/PRESCRIPTION_OCR_OVERHAUL.md` §3 Phase 0.
